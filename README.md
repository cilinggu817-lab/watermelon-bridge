# 西瓜搬家 🍉

少夜版与 Kira 版西瓜瓣备份双向转换器。

所有解压、转换和打包都在浏览器本地执行；不上传聊天记录、设置或密钥。此仓库只包含网站代码及本地运行依赖。

- 适配已核对的两版 schema 43 数据库，未知结构会停止转换。
- 保留聊天正文、分支、设置和备份中已有的附件。
- Kira 转少夜时，将明确标记的自动背景信息保存到附加元数据，避免显示成聊天气泡。
- 请先备份目标 App 的现有数据。转换不会合并现有聊天，实际导入仍需在 Android App 中验证。

GitHub Pages 从 main 分支根目录发布。部署文件来自原转换器已发布修复版本 d59b13aae70a7e888c1249c4184fb67ab0b5cf99。

SQL.js 和 fflate 的授权文件位于 vendor 目录。
